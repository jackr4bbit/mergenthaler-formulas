# Mergenthaler Formulas
A Mergenthaler plugin for displaying a widget for rearranging formulas.

## Installation

```bash
pip install git+https://github.com/jackr4bbit/mergenthaler-formulas
```

## Usage

In your Mergenthaler Markup, use
```mgmarkup
:{e=m*(c^2)}:
```
to get a representation of the equation.
